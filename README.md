# AEM Sample Project 

#### Este projeto consiste na geração de Estrutura de Um Projeto AEM as Cloud Service usando Apache Maven, bem como a customização de novos componentes. O Archetype deste projeto foi configurado para a estrutura Multi Pages Application (MPA).
